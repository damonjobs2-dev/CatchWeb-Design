# CatchWeb-Design 设计规范展示页 · DESIGN.md

状态：2026-11-06 用户暂定版，文档风格版本 1.0。
范围：Skill 产出的设计规范前端展示页。它定义展示框架；被分析网站的设计事实由每次交付目录中的 DESIGN.md 定义。

## 设计方向与使用方式

采用“清晰规范文档”：白底、克制的强调色、样例优先、参数紧贴样例、大章节以留白区分。适合设计系统、研究报告、帮助中心和文档型后台。用于其它业务网站时，可迁移其排版、色彩角色和组件表达，业务流程、数据结构和产品专属交互需单独定义。

实现以同目录上级的 assets/design-document.css 为样式源，assets/design-page.html 为通用生成模板，assets/study-navigation.js 为连续阅读目录逻辑。使用 scripts/build-page.py 与配套模板生成实际展示页。保持既有字体、布局和样例密度；新增内容复用这些约定。

## 信息结构

- 概览：整体与设计风格。
- 基础：色彩、字体、间距、布局、圆角、边框、阴影、图标。实际采集且有展示价值才显示。
- 页面：导航、按钮、卡片、标签、输入与搜索、表单、弹窗与浮层，以及有独立价值的网站特色组合。
- 交互动效：有证据的触发、变化、时序及预览。

目录与正文一一对应。基础内容连续滚动；目录点击定位到章节，阅读位置变化更新高亮，网址锚点只负责定位。到达页面底部时选中最后一个实际章节；重新向上滚动、调整窗口、恢复锚点后重新判断。每次最多一个当前项。空分类省略。

## 品牌色适配

固定：白色框架、深灰正文、中性分割线、字体体系、字号、栅格和留白。可变：导航强调色、选中浅底、演示画布浅底、辅助标尺和文档控件焦点色。每个站点从有证据的品牌色或主要交互色选一个文档强调色；缺乏证据时沿用默认蓝色 #336DF4。

以品牌色的淡色混合形成浅底，正文保持中性。亮黄、荧光或低对比色用同色相深色作为小字和选中标识，目标文字对浅底对比度至少 4.5:1。原始品牌色仍原样出现在色卡与证据中。生成器的 documentTheme 接受 accent、basis、evidenceIds，accent 为六位 HEX；这是文档配色配置，不属于原站 Token。

## 字体与排版

文档字体：-apple-system、BlinkMacSystemFont、Segoe UI、PingFang SC、Microsoft YaHei、sans-serif。数值和代码：ui-monospace、SFMono-Regular、Menlo、Consolas、monospace。使用本机可用字体，不强行下载字体。原站样张可使用已取得的原站字体，未取得则明确替代。

| 层级 | 桌面 | 字重 | 行高 |
|---|---|---|---|
| 文档标题 | 32px | 620 | 1.35 |
| 样例页章节标题 | 26px | 600 | 1.35 |
| 通用模板小节标题 | 23px | 600 | 1.35 |
| 正文 | 15px | 400 | 1.65 |
| 侧栏目录 | 14px | 400；选中 600 | 22px |
| 参数标签与注释 | 13px | 常规 | 约 20–22px |
| 参数数值 | 15px 等宽 | 常规 | 22px |

移动端文档标题 28px / 1.4，样例章节标题 23px；细节以共享 CSS 为准。文字左对齐；正文限制约 72ch。用自然语言和带标签的参数，不让读者解码斜线分隔的数字。文档颜色显示大写 HEX，透明度单列。

## 布局与尺寸

- 桌面顶栏 68px，侧栏宽 240px，顶部保留 CatchWeb-Design 标识、设计规范及来源入口。
- 连续样例正文从侧栏右侧起，左右内边距 64px，上部 45px，底部 100px。中等宽度按 CSS 收紧；通用模板为右侧小节目录预留空间，1200px 及以下收起该目录。
- 侧栏内边距约 18px，目录项内边距 10px 14px、5px 圆角，选中指示条 2px。
- 大章节间距约 57px，标题至内容约 22px；样例、标题、参数共享对齐轴线。
- 760px 及以下使用单栏，左右 20px，顶栏保留 68px，目录折叠为可展开入口。正文从侧栏右侧位移改为全宽，底部留白 72px。
- 表格在窄屏允许局部横向滚动；页面整体不横向溢出。侧栏目录过长时独立滚动。

## 样例表达

色彩：色块、名称、色值、应用位置和必要的角色说明。背景依赖和透明度保留，测量值与推测分开。

字体：按字号从大到小展示，实际文本作为样张，字号/字重/行高/字距/字体分别标注。

间距：条形与数值展示实测间隔。内边距以容器和内容示意，标明上下左右；桌面四列、窄屏两列，图示标注约 12px。不把示意缩放后的尺寸写作原站数值。

圆角：紧凑表格三列为应用位置、数值、局部转角预览。局部转角放在受限画布里，以便比较大圆角；保留原始数值，不让所有样例都压缩成看不出差别的胶囊。

边框：小尺寸样例与线宽、样式、颜色侧排；现有样例演示区最小高约 76px、内边距 16px、8px 圆角。

阴影：一个代表性白色表面与易读参数侧排。默认演示面约 200px 宽、最小高 116px；内部样例 104×52px、10px 圆角属于文档示意。颜色、不透明度、水平/垂直偏移、模糊和扩散逐项列出；多层阴影逐层说明。原始阴影不加深，未知参数写未测量。窄屏上下排列。

组件：简单按钮/标签在 compact 展示面集中比较；完整卡片/表单使用 panel；浮层使用 overlay 画布。通用卡片下分功能、产品、评价等用途变体。状态比较时统一内容与尺寸，原站未确认的状态保留缺口。复杂组件允许局部定制代码，文档外框仍复用共享 CSS。

## 交互与无障碍

- 目录锚点定位与手动滚动一致，旧锚点不锁住当前高亮。底部选中最后节，上滚恢复实际章节；加载、字体完成、窗口变化均更新。
- 移动目录可打开、选择后关闭，Esc 关闭并返回触发按钮。
- 链接、按钮、输入框保留可见键盘焦点。文档焦点样式与原站采集状态分别标记。
- 演示操作在本地完成；提交、购买等行为用明确示例表达，未获授权不触发原站业务。
- 动画只播放有测量数据的效果，尊重 prefers-reduced-motion；未测量的时间或缓动保留未知。

## 冻结与扩展

后续 Skill 输出默认沿用本规范。品牌强调色及其浅色辅助层可以变化，数据和样例因站点变化；核心版式、字级和演示结构保持稳定。用户明确提出新的版式方向时再修订规范版本，而不是每次生成都重新设计外框。

验收：桌面与窄屏无整体横向溢出，目录到底部正确高亮最后节、返回上方恢复高亮，目录可用键盘操作，图像和附件有效。至少以两个不同品牌色验证主题变化；同时确认原站样例的颜色与数值未被文档主题覆盖。

## 可用性与改版边界

这份文档提供可直接实现的框架、样式角色、尺寸、组件表达和交互规则，可作为网站改版的设计输入。它没有定义任意业务网站的完整产品流程，也不证明被分析站点的所有状态已经测量。给开发 Agent 时同时提供目标页面和改版范围，要求复用这些规则并完成真实浏览器验收。

每次分析的另一个 DESIGN.md 应写被分析网站本身的视觉规范：色彩、字体、布局、表面、组件、动效、响应式与适用边界；它与本份文档框架规范分别交付，不混写品牌事实。
